## 🚀 Projects That Define My Work

Not just repositories. Systems built to solve actual engineering problems.

### 01. Conduit — Team MCP Gateway



`Kubernetes` `Helm` `MCP` `React` `Fastify` `MongoDB` `Gemini`

A centralized gateway that allows teams to connect multiple upstream MCP servers through a single authenticated Streamable HTTP endpoint.

- Built a custom MCP gateway with tool routing, name-collision handling, per-call timeouts and circuit breakers.
- Developed a custom WooCommerce MCP server and a React dashboard with an LLM-powered chat agent.
- Implemented per-user tool execution and comprehensive audit logging.
- Secured the platform using RBAC, hashed and revocable API keys, SSRF protection, rate limiting and Kubernetes NetworkPolicies.
- Created reusable Helm charts for local k3d/k3s and VPS deployments.
- Tested using Vitest and Playwright.

**Engineering highlight:** An unavailable upstream service should never bring down the entire gateway.

---

### 02. Pushr — Mini-Heroku / Push-to-Deploy PaaS



`Kubernetes` `Docker` `Kaniko` `Buildpacks` `Cloud-Native`

Building a miniature Platform-as-a-Service inspired by Heroku.

- Designing a push-to-deploy workflow on Kubernetes.
- Developing container image building using Kaniko and Buildpacks.
- Separating cluster infrastructure, image building and deployment into independently verifiable phases.
- Using Antigravity as an AI-assisted development tool while validating each phase through dedicated checks.

**Engineering highlight:** Building the infrastructure behind application deployment, not just the application itself.

---

### 03. ReconcileAI — AI Finance Controller



`React` `Node.js` `MongoDB` `Claude API` `Gemini API`

An AI-assisted financial reconciliation engine designed to simplify complex Razorpay settlement reconciliation.

- Built a three-tier matching engine to break lump-sum payment gateway settlements into individual order-level transactions.
- Designed GST and payment-fee decomposition.
- Implemented human-in-the-loop approvals for uncertain matches.
- Added an immutable audit trail to maintain traceability and accountability.

**Engineering highlight:** Financial automation needs explainability, validation and human oversight — not just AI predictions.
